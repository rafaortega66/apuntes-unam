Clase 01 — Von Neumann vs Harvard, CISC/RISC y el pipeline

Apuntes de clase · 26-ago-2026 · toca Tema 1 (estructura básica) y Tema 4 (pipelining). Las partes marcadas [?] son de letra difícil de leer — verificar.

En corto

  • Von Neumann: una memoria para datos e instrucciones → una instrucción a la vez (se asocia a CISC).
  • Harvard: memorias separadas → trae instrucción y dato a la vez (se asocia a RISC).
  • CISC = instrucciones complejas, pocas líneas; RISC = instrucciones simples tipo carga / almacena.
  • Ciclo: Fetch → Decode → Execute → Write Back; con pipeline sale un resultado por ciclo de reloj.

Las instrucciones son "físicas": cada una cuesta tiempo (ciclos de reloj).

CISC vs. RISC

CISC — instrucciones complejas, cercanas a un lenguaje de alto nivel; el mismo trabajo se escribe en pocas líneas. Ejemplo de estilo (pseudocódigo de la clase):

for (i = 0; i < n; i++);
set(i) 0;
...   EST1        ; etiqueta   [?]

RISC — instrucciones simples y uniformes tipo carga / almacena / opera. Ejemplo de pseudo-ensamblador de la clase (transcripción aproximada):

LDA A, (i)        ; cargar A desde memoria
SUB A, (o)        ; [?] "SBtA"
STA (i)           ; almacenar A en memoria
LDA (i)
LDB (w)
SUB A, B          ; A <- A - B
LDC EST1, 1
JL2              ; salto  [?]
LDA i
INC A            ; [?] "IWC A"
STA i

Ciclo del procesador y pipeline

Cada instrucción pasa por etapas. En los apuntes aparecen cuatro:

  1. Fetch — traer la instrucción de memoria.
  2. Decode — decodificarla.
  3. Execute — ejecutarla (en los apuntes: "stage? preguntar"). En un pipeline RISC clásico aquí se suele intercalar además una etapa de acceso a memoria.
  4. Write Back (WB) — escribir el resultado en el registro.

Con pipelining, mientras una instrucción se ejecuta, la siguiente se decodifica y la siguiente se busca: varias instrucciones avanzan a la vez, desfasadas un ciclo. Éste es el diagrama espacio-tiempo que quedó marcado como «foto» en los apuntes:
