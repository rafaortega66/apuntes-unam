Métodos de filtrado

Evalúan cada característica de forma independiente del algoritmo de aprendizaje, antes de entrenar: 1) calcular una medida de relevancia, 2) ordenar por puntuación, 3) quedarse con las k mejores o las que superan un umbral.

Correlación de Pearson — relación lineal entre dos variables cuantitativas continuas.

r = Σ(xᵢ − x̄)(yᵢ − ȳ) / √( Σ(xᵢ − x̄)² · Σ(yᵢ − ȳ)² )
   r > 0 correlación positiva · r = 0 sin correlación lineal · r < 0 negativa

Chi-cuadrado (χ²) — dependencia entre variables categóricas: compara frecuencias observadas Oᵢ vs. esperadas Eᵢ bajo la hipótesis nula de no asociación.

χ² = Σ (Oᵢ − Eᵢ)² / Eᵢ          Eᵢ = (total fila × total columna) / total general

Ejemplo (compra sí/no × hombre/mujer, 200 casos): esperados = 55/45; χ² = 4.09 + 5.00 + 4.09 + 5.00 = 18.18. Grados de libertad gl = (filas−1)(columnas−1) = 1; χ²crítico (α = 0.05) = 3.841. Como 18.18 > 3.841 → variables dependientes → característica relevante.

ANOVA F-score — compara la varianza entre grupos con la varianza dentro de los grupos; F = varianza entre grupos / varianza dentro de los grupos. F alto → las medias de los grupos difieren → la variable aporta.

Es como revisar las manzanas en una frutería y desechar las podridas antes de empezar a cocinar, basándote solo en su aspecto y no en el sabor del platillo final.Dónde falla la analogía: Deja de funcionar si dos ingredientes que por separado parecen inútiles se combinan para darle todo el sabor al platillo final.

Por qué importa / con qué se conecta

Representa la alternativa de selección de características previa al entrenamiento del modelo, útil cuando no se tienen suficientes recursos computacionales para entrenar múltiples clasificadores.

Métodos Wrapper (de envoltura)

Usan un algoritmo de aprendizaje como caja negra para evaluar iterativamente el rendimiento (exactitud del clasificador) de distintos subconjuntos de variables. El orden de las características en la matriz de entrada no importa para el modelo (A+B = B+A).

Forward Selection (hacia adelante): iniciar con subconjunto vacío (o con 1 característica; ej. B → 70 %). Añadir una variable a la vez, entrenar y evaluar; consolidar si mejora (B+A mejora; B+A+C → 80 %). Parar cuando añadir empeora (B+A+C+D baja 1 %). Óptimo: {B, A, C}.

Backward Selection (hacia atrás): iniciar con todas ({A,B,C,D} → 82 %). Quitar una variable a la vez; consolidar la remoción si mejora o mantiene (quitar A → 83 %; quitar D → 84 %). Parar cuando quitar cualquiera de las restantes desploma el desempeño (quitar B −24 %, quitar C −14 %). Óptimo: {B, C} con 84 %.

Durante el ejercicio de Backward, un alumno preguntó si para el conjunto inicial se puede asumir que no importa el orden de las características — el profesor confirmó que el orden original de las columnas es completamente irrelevante para los modelos de aprendizaje.

Exhaustive Feature Selection: evaluar todas las combinaciones (individuales, parejas sin repetir, tríos, todas). Complejidad O(2^d). Ventaja: garantiza el óptimo global ({B,C} 84 % > 82 % con las 4). Desventaja: un modelo entrenado por combinación → inviable con más de ~15–20 características.

El profesor preguntó al grupo qué problema técnico le veían a este método; un alumno respondió correctamente que "escala muy rápido hacia arriba" porque el crecimiento computacional es exponencial. El profesor confirmó: cada combinación implica entrenar e inferir un modelo completo (desde un árbol simple hasta uno más complejo), y aunque garantiza el óptimo global, se vuelve inviable con más de 15-20 características. Otro alumno preguntó si antes de llegar a la selección exhaustiva habría que hacer una discriminación previa — el profesor aclaró que este método realiza la discriminación por sí mismo; es una alternativa directa que no necesita un filtrado previo.

Explicado en simple

Es como probar distintas combinaciones de ingredientes preparando un platillo cada vez, agregando uno a uno (forward), quitando uno a uno (backward) o probando todas las recetas posibles (exhaustive).Dónde falla la analogía: Falla cuando tienes cientos de ingredientes, pues preparar una receta completa para cada combinación tomaría años o agotaría la cocina.

Por qué importa / con qué se conecta

Permite evaluar combinaciones de características usando el desempeño del propio clasificador, donde Forward es ideal para pocas características relevantes, Backward da una buena línea base inicial y Exhaustive garantiza el óptimo global a costo exponencial.

Errores comunes: Creer que en Forward Selection se pueden eliminar características ya agregadas o que en Backward Selection se pueden reincorporar variables previamente descartadas.

Métodos Embebidos

La selección ocurre durante el entrenamiento: el propio modelo tiene un algoritmo de selección intrínseco que asigna pesos / importancias y penaliza o elimina las variables que no aportan.

Regularización Lasso (norma L1) — Least Absolute Shrinkage and Selection Operator. Modifica la función de pérdida (qué tanto te equivocas: predicción vs. realidad) añadiendo el término Σ |Wⱼ|.

  • Cada variable tiene un peso Wⱼ. W alto (15–20) → muy importante. Si W baja (0.5) o llega a exactamente 0 → el modelo descarta la variable. El algoritmo ajusta los W dinámicamente para optimizar la clasificación.

Árboles de decisión — reglas de umbral Xⱼ ≤ t (según se cumpla, el flujo va al nodo hijo izquierdo o derecho).

  • En cada nodo se evalúan todas las características y se elige la que da la mayor reducción de impureza (Gini o entropía).
  • Importancia de una característica = Σ (muestras del nodo / total) × reducción de impureza, sumada sobre todos los nodos que usan esa variable.
  • Las importancias se normalizan para que sumen 1.0 y se seleccionan las que superen un umbral (ej. > 0.5) o las top-K.
Explicado en simple

Es como un chef experimentado que mientras cocina va ajustando la flama y descartando condimentos sobre la marcha según el sabor que va tomando el guiso.Dónde falla la analogía: Deja de servir si el modelo utilizado carece de un mecanismo interno de penalización o reglas de decisión basadas en umbrales.

Por qué importa / con qué se conecta

Integra la selección dentro del mismo algoritmo de entrenamiento mediante penalización de pesos L1 (Lasso en la función de pérdida) o cálculo de importancia normalizada en nodos de árboles de decisión.

Criterios de diseño (selección de características)

No hay regla fija: la elección del método depende de los recursos de cómputo y de la naturaleza de los datos. Sin poder de cómputo → usar métodos embebidos o filtrado previo al entrenamiento (wrapper/exhaustive resultan inviables). En la práctica es válido y recomendable comparar 2 o más métodos sobre el mismo problema para contrastar resultados y justificar las decisiones de diseño.

Explicado en simple

Es como decidir qué herramientas llevar a un viaje considerando el espacio en tu mochila, cuánto pesa cada una y si vale la pena llevar dos herramientas parecidas.Dónde falla la analogía: La analogía no aplica si se asume que existe un único criterio perfecto e inmutable independientemente del problema o de la computadora disponible.

Por qué importa / con qué se conecta

Guía la elección del método de selección según los recursos computacionales disponibles, el número total de características y la naturaleza del problema, permitiendo incluso comparar dos métodos para justificar decisiones de diseño.

Errores comunes: Pensar que un método de selección es intrínsecamente más correcto que otro, cuando el profesor aclaró que es una decisión de diseño basada en recursos y criterios.

Reducción de dimensionalidad — qué es y por qué

A diferencia de la selección (conserva intactas las variables originales), la reducción de dimensionalidad proyecta los datos a un espacio nuevo de menor dimensión mediante combinaciones matemáticas: las nuevas variables ya no representan lo mismo (ya no son peso, edad o género, sino combinaciones de ellas).

Importa porque operar con vectores de alta dimensión provoca: mucho más tiempo de cómputo, mucho más almacenamiento, y sobre todo degradación del rendimiento de los modelos (maldición de la dimensionalidad).

Explicado en simple

Es como tomar una escultura tridimensional y proyectar su sombra en una pared de dos dimensiones para ver su silueta más clara sin cargar la escultura completa.Dónde falla la analogía: Falla porque la sombra crea un espacio con variables combinadas completamente nuevas que ya no representan medidas individuales como peso o altura.

Por qué importa / con qué se conecta

Transforma el espacio original de alta dimensión a uno de menor dimensión creando combinaciones lineales para reducir tiempo de cálculo, almacenamiento y degradación del modelo, proyectando hacia las direcciones de máxima varianza (PCA).

Errores comunes: Asumir que la reducción de dimensionalidad conserva las variables originales con sus significados físicos, cuando en realidad las combina creando nuevos ejes ortogonales.

examenPCA — Análisis de Componentes Principales

Transforma variables posiblemente correlacionadas en componentes principales no correlacionados, ordenados por la varianza que explican. Asume que la dirección de máxima varianza es la más informativa (ahí los patrones de las clases quedan más separados).

Combinación lineal: Z = A₁X₁ + A₂X₂ + … — Xᵢ variables originales, Aᵢ coeficientes (escalares), Z variable transformada.

Vectores y valores propios: un vector propio v mantiene su dirección al multiplicarlo por la matriz A, solo cambia de magnitud; ese factor es el valor propio λ.

A v = λ v            (A = matriz de covarianza; v = dirección; λ = varianza en esa dirección)
Z = W · X           (W = matriz de vectores propios; X = datos originales; Z = proyección)

Algoritmo (método de la matriz de covarianza):

  1. Centrar y escalar los datos: restar la media de cada característica (y opcionalmente dividir entre su desviación estándar). Indispensable para que variables con escalas grandes (salarios de 15 000 a 1 000 000) no dominen sobre las pequeñas (edades de 18 a 65).
  2. Matriz de covarianza con X centrada de N×D: Σ = (1/(N−1)) Xᵀ X. Es cuadrada; mide la variabilidad conjunta entre parejas de variables.
  3. Ecuación característica det(Σ − λI) = 0 (evita la solución trivial) → valores propios λ₁, λ₂, … y vectores propios v₁, v₂, …
  4. Ordenar los λ de forma descendente por varianza explicada; tomar los primeros K vectores propios → matriz W_K. Proyección: X_nuevo = X · W_K, dimensiones N×K con K < D.

PC1 = dirección de máxima varianza. PC2 = segunda mayor varianza, estrictamente ortogonal a PC1. Todos los componentes son ortogonales entre sí (base ortogonal; ninguno se obtiene por combinación lineal de los otros).

PCA — ejemplos numéricos (diapositivas Clase 5)

Ejemplo 1: Σ = [[4, 2], [2, 3]]

det(Σ − λI) = (4−λ)(3−λ) − 4 = λ² − 7λ + 8 = 0   →   (λ−1)(λ−8) = 0   →   λ₁ = 8 , λ₂ = 1

λ₁ = 8:  (Σ − 8I) w = 0  →  fila 1:  −4 w₁ + 2 w₂ = 0  →  w₂ = 2 w₁
         v₁ = [1, 2]ᵀ      normalizado:  v₁ = (1/√5) [1, 2]ᵀ
λ₂ = 1:  (Σ − I) w = 0   →  fila 1:  3 w₁ + 2 w₂ = 0   →  w₂ = −(3/2) w₁
         v₂ = [2, −3]ᵀ     normalizado:  v₂ = (1/√13) [2, −3]ᵀ

Ejemplo 2: Σ = [[4, 1], [2, 3]]

det(Σ − λI) = (4−λ)(3−λ) − 2 = λ² − 7λ + 10 = 0   →   λ₁ = 5 , λ₂ = 2
   v₁ = [1, 1]ᵀ ,  v₂ = [1, −2]ᵀ

Recordatorio de las diapositivas: la suma de todos los valores propios = varianza total; varianza explicada acumulada = (Σᵢ₌₁..ₖ λᵢ) / (Σᵢ₌₁..d λᵢ).

Los alumnos respondieron correctamente las dos soluciones de la ecuación característica, y al resolver el sistema homogéneo para cada una obtuvieron los vectores directores correspondientes (pendientes de normalizar) — confirmando en vivo que el procedimiento se puede replicar con cualquier matriz de covarianza 2×2.

Explicado en simple

Es como resolver una ecuación matemática en el pizarrón para encontrar los ángulos exactos donde se estira o encoge una figura sin cambiar su forma.Dónde falla la analogía: Deja de funcionar si la matriz no se centra previamente restando la media, provocando que los datos escalados incorrectamente distorsionen los valores propios.

Por qué importa / con qué se conecta

Muestra la resolución matemática paso a paso calculando el determinante det(C - lambda I) = 0 para obtener los eigenvalores (como lambda=8, lambda=1 o 5 y 2) y sus eigenvectores asociados que definen la nueva base ortogonal.

Errores comunes: Olvidar elevar al cuadrado los valores singulares (s_i²) al calcular la varianza explicada cuando se utiliza SVD en lugar de las lambdas directas de la matriz de covarianza.

examenCómo elegir K (número de componentes) 
varianza explicada (individual) = λᵢ / Σ λⱼ        (la acumulada llega a 1.0 = 100 %)
  1. Regla del codo (Elbow): graficar la varianza acumulada por componente; el "codo" es donde la pendiente cambia bruscamente y la curva se aplana. Ej.: 13 componentes, codo en el 5.º → K = 5.
  2. Umbral de varianza: fijar de antemano el % a retener (típico 90 %); tomar los componentes acumulativos necesarios (ej. 8 componentes explican el 91 %).
  3. Criterio de Kaiser: conservar solo los componentes con λ > 1 (aportan más que una sola variable original).
examenPCA por SVD (Descomposición en Valores Singulares) 
X = U Σ Vᵀ
   U   = vectores singulares izquierdos
   Vᵀ  = transpuesta de los vectores singulares derechos
   Σ   = matriz DIAGONAL con los valores singulares en orden descendente
  • Los vectores singulares derechos (V) = las direcciones principales (componentes de PCA). Los valores singulares = raíz cuadrada de los valores propios de la matriz de covarianza.
  • Algoritmo: (1) centrar / normalizar X (restar la media); (2) aplicar SVD directo sobre X centrada; (3) obtener Σ y V.
  • ⚠️ Varianza explicada en SVD: hay que elevar al cuadrado los valores singulares → σᵢ² / Σ σⱼ². Olvidarlo da resultados erróneos (error muy común en exámenes y en código).
  • Ventajas: estabilidad numérica muy superior; funciona sobre matrices no cuadradas; evita calcular Xᵀ X (costoso); eficiente para datasets masivos con N ≫ D o D ≫ N. Es lo que usan la mayoría de las bibliotecas.
🧠 Ponte a prueba

Intenta contestar cada pregunta antes de abrirla. Recordar por tu cuenta es lo que fija la información; releer no la fija.

1. ¿Cuál es la diferencia fundamental entre la selección de características y la reducción de dimensionalidad según lo expuesto en clase?

La selección de características conserva un subconjunto de las variables originales manteniendo su significado físico (como edad o peso), mientras que la reducción de dimensionalidad proyecta los datos a un nuevo espacio de menor dimensión donde las nuevas variables son combinaciones lineales que ya no representan las características originales.

2. Explica con tus palabras por qué la selección exhaustiva de características (Exhaustive Feature Selection) garantiza encontrar el óptimo global y cuál es su principal desventaja.

Garantiza el óptimo global porque prueba absolutamente todas las combinaciones posibles de características evaluando un modelo para cada una; su principal desventaja es que escala de forma exponencial y se vuelve computacionalmente inviable cuando se tienen más de 15 o 20 características.

3. Dada la matriz de covarianza C con ecuación característica obtenida det(C - lambda I) = 0 que resulta en lambdas igual a 5 y 2, ¿cuál es la varianza explicada por el primer componente principal?

La varianza total es la suma de los valores propios (5 + 2 = 7), por lo que la varianza explicada por el primer componente asociado a lambda = 5 es 5 / 7, lo que equivale aproximadamente al 71.4% de la varianza total.

4. Compara los algoritmos de selección de características Forward Selection y Backward Selection en términos de su punto de partida y sus limitaciones de modificación.

Forward Selection inicia con un conjunto vacío y añade características una a una sin poder eliminar ninguna variable ya agregada; Backward Selection inicia con todas las características y las elimina una a una sin poder reincorporar ninguna variable previamente descartada.

5. ¿Cómo funciona la regularización L1 de Lasso como método embebido para la selección de características?

Lasso añade la norma L1 de los pesos W a la función de pérdida del modelo durante el entrenamiento, asignando penalizaciones a los pesos de modo que a las características menos importantes se les reduce su peso a valores muy pequeños o directamente a cero para eliminarlas.

6. ¿Cuáles son las tres reglas o criterios heurísticos explicados en clase para determinar cuántos componentes principales K conservar en PCA?

La regla del codo (elegir el punto donde la curva de varianza acumulada se dobla y detiene su cambio abrupto), el umbral de varianza (fijar un porcentaje deseado como el 90% y conservar los componentes necesarios) y el criterio de Kaiser (conservar los componentes cuyo valor propio lambda sea mayor a 1).

7. En la implementación de PCA mediante Descomposición en Valores Singulares (SVD), ¿cuál es la fórmula para calcular la varianza explicada de cada componente y qué precaución enfatizó el profesor?

La fórmula es s_i² / sum(s_j²), donde s_i representa los valores singulares de la matriz Sigma. El profesor enfatizó que no se debe olvidar elevar cada valor singular s_i al cuadrado, a diferencia de las lambdas directas de la matriz de covarianza.

8. ¿Por qué PCA proyecta los datos hacia las direcciones de máxima varianza y qué asunción se hace al usarlo para clasificación?

Proyecta hacia la máxima varianza para retener la mayor cantidad de información del conjunto original en una base ortogonal, asumiendo que en las direcciones donde existe mayor dispersión de los datos será más factible separar y clasificar los patrones.
