3.3 Schedulers de Tiempo Real

Tipos de tiempo real

-Tiempo real duro (hard real time)
	-Ejecución crítica
		-El sistema se desetabiliza si el cómputo no se realiza a tiempo y puede no ser reestabilizable.
		-Retrasos en el cómputo pueden tener consecuencias catastróficas (para todo el sistema o para otros).
	-Todos los plazos deben cumplirse

-Tiempo real flexible (soft real time)
	-Ejecución no crítica
		-El sistema podría desestabilizarse si el cómputo no se realiza a tiempo, pero puede reencausarse.
		-Los retrasos en el cómputo son inconvenientes, pero no tienen consecuencias graves.
	-La ejecución de las tareas debería cumplirse dentro del plazo.

Distinción
-En RT no se habla de procesos sino de tareas.
-Las tareas son repetitivas y (normalmente) se ejecutan a completitud.
-Todas las tareas dependen del proceso principal o raíz
	-No hay procesos independientes
	-El proceso raíz administra el acceso al espacio de memoria compartida.

Tipos de tareas en sistemas RT
-Periódica (P)
	-Tiene deadline
	-Ocurre periódicamente (a intervalos de tiempo previamente conocidos)
-Aperiódica (A)
	-Tienen deadline.
	-Ocurre de forma espontánea.
	-Se considera con anticipación para la planificabilidad del sistema.
-Esporádicas (S)

¡OJO!
Algunos autores invierten la notación para tareas aperiódicas.

Planificabilidad
-Lo más importante durante el diseño de un sistema RT es definir si el sistema es planificable
-La planificabilidad depende de las tareas que se consideren, su consumo, periodo, y el tipo de scheduling.
