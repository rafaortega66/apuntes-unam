# 9. Manejadores de dispositivos (drivers)

## El controlador

### Qué es
El **controlador** (*device driver*) es **el software que sirve de interfaz y se encarga de gestionar y controlar el hardware**. Es **la liga entre el hardware y las demás capas** de software (SO, middleware, aplicaciones). Una función del SO es **arbitrar el acceso a los dispositivos de E/S**: las aplicaciones **nunca acceden directamente** al hardware, sino a través de servicios del SO.
- No todo se arbitra igual: la **cámara es de uso exclusivo** (si Zoom la abre, queda bloqueada) y el **micrófono se comparte**. Para mandar la cámara a dos programas se usa un intermediario como **OBS**, que crea cámaras virtuales.

!!! 😂 Para acordarte: la cámara y Black Mirror
«El micrófono se puede compartir, pero la cámara no: si entras a una página donde dicen que hay "mujeres maduras en tu área buscando ingenieros" y le das clic, **hay un gordo barbón que te quiere encender la cámara**… ¿No vieron el episodio de **Black Mirror** donde el hacker graba al chavo en su recámara?» Por eso Zoom aplica un **candado** (adquisición) y nadie más la usa hasta que la **libera**.

### Las capas
Del modelo más simple al más complejo: aplicación → sistema → **controladores** → hardware; luego con **SO** en medio; y luego con **middleware** encima del SO. **Cada capa extra cuesta rendimiento.**

!!! 😂 Para acordarte: Snap contra nativo
«Misma máquina, mismo kernel 6.1, misma glibc y mismo escritorio Xfce: en **Debian** Firefox abre en **10 segundos con 340 MB**; en **Ubuntu 24, 45 segundos y 1.4 GB**. ¿Por qué? Porque Ubuntu lo corre sobre **Snap**, parches sobre parches dentro de un contenedor, y Debian lo compila nativo.» Igual las apps bancarias hechas como página web dentro de un navegador, que tardan 40 segundos en abrir para consultar el saldo.

## Las funciones de un controlador

### Las 10 funciones
| Función | Qué hace |
|---|---|
| **Arranque** | Inicializa el hardware al encenderse o tras un reset |
| **Apagado** | Configura el hardware para suspender su consumo y apagarse |
| **Habilitación** | Permite que otro software **habilite** el hardware al vuelo |
| **Deshabilitación** | Permite que otro software lo **deshabilite** al vuelo |
| **Adquisición** | Permite que otro software tome **acceso exclusivo** (*lock*) |
| **Liberación** | Permite que otro software **suelte** ese acceso exclusivo (*unlock*) |
| **Lectura** | Permite que otro software **lea** del dispositivo |
| **Escritura** | Permite que otro software **escriba** en el dispositivo |
| **Instalación** | Permite que otro software **instale** el hardware al vuelo |
| **Desinstalación** | Permite que otro software lo **desinstale** al vuelo |
Ejemplos: el disco duro arranca, se identifica y pide ~1 A para girar; al expulsar en Linux se oye el click y se apaga el LED; el mouse informa su DMA, su IRQ y sus botones al instalarse; un disco, antes de desconectarse, vacía sus búferes, se desinstala, se deshabilita y se apaga (un mouse se desenchufa directo).
**Más funciones posibles:** **ACPI** (*suspend*, *stand-by*, *wake*), **estado** (*idle*, *busy*, *finished*), **modos de transmisión** USB (*control*, *interrupt*, *bulk*, *isochronous*) y **acoplamiento** (*mount*, *unmount*, *eject*).

!!! 😂 Para acordarte: la impresora que se come la tinta
Con ACPI, un escáner apaga su lámpara y el Wi-Fi baja potencia, «pero una impresora de inyección en suspend se apaga, y cuando le mandas *wake* **se le olvida que ya estaba limpia y vuelve a vaciar la mitad del cartucho en las esponjas**… En tercer semestre fui a imprimir una tarea y el cartucho negro estaba vacío de puras limpiezas. La tiré y me compré una láser que me duró toda la carrera.»

## 🎯 Controladores dedicados y genéricos

!!! 🎯 Pregunta de examen
El profesor: «Vamos a tener dos tipos de controladores y **esto es pregunta de examen**: los dedicados y los genéricos.»

| | **Dedicados** (*architecture-specific*) | **Genéricos** |
|---|---|---|
| Ligados a | **Componentes del procesador** | El **hardware de la tarjeta madre** y lo conectado a ella |
| Qué cubren | **Memoria integrada** (caché, MMU), **coprocesadores aritméticos** (FPU), **FPGA integrado** y otros periféricos del chip | **Buses** (SMBus, I²C, PCI, PCMCIA), **memoria externa** (caché L2+, memoria secundaria, bancos de DRAM) y **E/S integrada** (teclado, mouse, Ethernet, puertos serie y paralelo, USB) |
| Para qué | Decirle al procesador **cómo está organizado por dentro** y con qué recursos cuenta | Manejar todo lo que está **afuera del núcleo** |
Al despertar, el procesador no sabe cómo es: un Cortex-M0 no sabe si está solo (Blackpill) o con un gemelo (RP2040), ni un Cortex-M4 si está solo (Bluepill) o con un hermano y una FPU. Eso se lo dice el **dedicado**.

!!! 😂 Para acordarte: ¿Qué pasó ayer?
«El procesador, cuando se despierta, **tiene amnesia**: es como la película **¿Qué pasó ayer?**, no sabe de dónde salió el tatuaje ni por qué está todo irritado entre las piernas. **Alguien se lo tiene que recordar, y ese es el controlador dedicado**: "así está organizada tu memoria, tienes tanta caché, tus MMU están acá, te pusimos un coprocesador para senos y cosenos o una FPGA". **El genérico es para todo lo que está afuera del núcleo** en la tarjeta madre: PCI, SMBus, Ethernet, DRAM, USB.»

## Clasificación general

### Las seis categorías
| Categoría | Qué hace |
|---|---|
| **Puerto serie** | Control completo de la **UART/USART** y sus modos (y también I²C, SPI, SMBus) |
| **Red** | Todas las interfaces de red (**Ethernet, Wi-Fi**); implementan el **stack TCP/IP**; algunos protocolos con repetición. Las buenas tarjetas cifran y descifran solas para descargar al CPU |
| **Serial ATA** | Define una **AHCI**; acceso a dispositivos de alta velocidad con un sistema de archivos |
| **FLASH** | Controlador **de bloques** especial: borra, escribe y lee **en bloques** y **reparte el desgaste** para que todos los bloques tengan los mismos ciclos |
| **Buses** | PCIe, USB, SMBus: **identifican el dispositivo conectado** y le **reservan los recursos** |
| **Interrupciones** | Gestiona las interrupciones; es fundamental, así que **solo el kernel tiene acceso** |
**El modelo del controlador cambia según el dispositivo.** En **POSIX**, los servicios del SO (sockets, sistema de archivos, `/dev/xxx`, captura de video) se apoyan en drivers de bloques (SATA), de red (Ethernet), de caracteres (UART, TTY, puerto serie de Bluetooth) y de USB, y todos se cuelgan del **driver del bus PCI**. Un disco remoto montado por red (**NFS**) entra como dispositivo de bloques.

!!! 😂 Para acordarte
- **Red con WiMAX:** antenas de hasta 5 km que hacen de repetidoras: «si Telmex hubiera metido eso, con una sola antena conectaba a todos los pueblos de la sierra».
