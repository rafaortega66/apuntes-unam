# ASI — Equipo 10 — Proyecto Final

**Práctica 7: Infraestructura de servicios para una escuela**
Administración de Servicios de Internet · Mtro. Juan Ángel Calvillo Pérez

## Descripción del proyecto

Diseño, implementación y documentación de una infraestructura de servicios de
red (DHCP, DNS, servidor web, Samba y SSH) sobre máquinas virtuales, orientada
a las necesidades de conectividad y compartición de recursos de una
institución educativa.

Metodología de trabajo: **Scrum**.
